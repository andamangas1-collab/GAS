# GAS™ — Grand Affiliate System Platform

Modern, cloud-native Affiliate Marketing & E-Commerce Platform built with:
- **Framework:** Next.js 14 App Router, React 18, TypeScript, Tailwind CSS
- **Database:** Supabase Cloud PostgreSQL via Prisma ORM
- **Authentication:** NextAuth v4 (JWT session strategy with multi-role RBAC: Super Admin, Admin, User)
- **Features:** Direct vs. MLM dynamic engine, Value-to-Value (V2V) commerce, automated commissions, recognition badges, and live offers.
